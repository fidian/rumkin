This is a collection of how-to guides, informational documents, and other web pages that primarily give you instructions or helpful advice.

- [3rd Edition D&amp;D](dnd/) - Information about how to stay alive, our previous house rules, links to software, custom prestige classes, etc.

- [Access and MSSQL](ms-db/) - Little functions and bits of code for Microsoft Access and Microsoft SQL Server.
- [Building the Colosseum](colosseum/) - My journey to build a scale model of the Roman Colosseum (Flavian Ampitheatre) in Minecraft as accurately as possible.
