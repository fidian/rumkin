Ever have a weird problem that you couldn't figure out how to get rid of it? I have. Sometimes the information isn't even on the web when I search for the answer, or else the answer is split up and scattered across numerous web pages. Because of that, I have collected my goofy problems here on this page in the hopes that it will save another person some time.

- [7 Inch Laptop](7-inch-laptop/) - Installing Linux and overcoming hardware issues with a cheap and small laptop.
- [AWS Maximum Number of Interfaces Exceecded](aws-maximum-number-of-interfaces/) - Had difficulty making a new instance when we didn't hit our instance limit. What could have been the problem?
- [File Transfer Through Terminal](file-transfer-through-terminal/) - Sometimes one connects to a terminal through SSH and using SCP / rsync isn't an available option.
- [Linux on Averatec 6200](averatec-6200/) - Notes about getting this laptop to boot Linux and resolve some of the hardware issues.
- [Query Analyzer to Excel](export-qa-to-excel/) - Exporting results from Microsoft SQL Server's Query Analyzer, including the column headers.
- [Restoring Novell SDIF Encapsulated Files](novell-sdif-restore/) - You can restore Novell backups to a non-Novell system, but the files appear to be corrupt when restored.
- [Setting up Qmail on Gentoo](qmail-gentoo/) - Brief list of instructions necessary to get qmail up and running on an older version of Gentoo.
- [Uninstalling CSNW](csnw/) - DOS shells would display "Cannot load VDM IPX/SPX support" because of Novell's drivers.
- [Windows Domain Time Issues](windows-domain-time-diff/) - Solving the login error, `There is a time difference between the client and server`.

Yes, that is a short list. I don't believe in making a page to cover a problem whose answer is easily found with a search engine.
